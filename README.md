# HabitFlow

> Маленькие привычки. Замечательные результаты.

HabitFlow — это статический образовательный сайт о том, как формировать
полезные привычки. Гид по 21-дневному плану, объяснение нейронауки, готовые
сценарии, методы (стек привычек, правило двух минут и др.), интерактивный
тест и локальный трекер — без сервера и без аккаунтов.

**Сигнатурная фишка** — страница `/daily`: каждый день одно новое произведение
(скороговорка или короткое стихотворение) для тренировки памяти. Контент
выбирается детерминированно по дате, прогресс хранится в `localStorage`.

## Стек

- **Next.js 14** (App Router, TypeScript)
- **Tailwind CSS** + `@tailwindcss/typography`
- **MDX** через `next-mdx-remote/rsc` + `gray-matter` (статьи в `/content/habits`)
- **next-themes** — переключение тёмной/светлой темы
- **framer-motion** — мягкие анимации появления
- **Recharts** — недельный график активности в трекере
- **lucide-react** — иконки
- Никакой базы, API-роутов, авторизации — всё статично и хостится на Vercel
  без какой-либо настройки.

## Локальная разработка (Windows / PowerShell)

Предполагается, что у вас установлен Node.js 18+ и npm.

```powershell
# из папки проекта
npm install
npm run dev
```

Сайт откроется на http://localhost:3000.

Другие команды:

```powershell
npm run build   # сборка для продакшна
npm run start   # запуск собранной версии
npm run lint    # eslint
```

## Деплой на Vercel

Проект полностью совместим с Vercel «из коробки» — никакой конфигурации не
требуется.

### Способ 1: через сайт Vercel (рекомендуется)

1. Зайдите на https://vercel.com и войдите через GitHub.
2. Нажмите **Add New… → Project**.
3. Выберите репозиторий `mamatovamarzhan/habitflow-ai`.
4. На экране настройки оставьте всё по умолчанию:
   - Framework Preset: **Next.js** (определится автоматически)
   - Build Command: `npm run build`
   - Output Directory: `.next`
   - Install Command: `npm install`
5. Нажмите **Deploy**.

Через 1–2 минуты Vercel выдаст вам URL вида
`https://habitflow-xxx.vercel.app`. Каждый последующий push в `main` будет
автоматически переразвёрнут.

### Способ 2: через CLI

```powershell
npm install -g vercel
vercel login
vercel        # первый раз — задаст несколько вопросов
vercel --prod # боевой деплой
```

## Как добавить новую статью-привычку

Просто создайте новый `.mdx` файл в `content/habits/`:

```mdx
---
title: Прогулка после ужина
summary: Самая недооценённая привычка — 10 минут пешком после еды снижают сахар крови и улучшают сон.
difficulty: лёгкая        # лёгкая | средняя | сложная
time: 10 минут            # отображается в библиотеке и работает с фильтром
category: body            # morning | mind | body
emoji: 🚶
---

## Почему это важно

Ваш текст в Markdown / MDX...

## С чего начать

...
```

Файл будет автоматически:

- появится на странице `/habits` (с фильтрами по сложности и времени),
- получит свой URL `/habits/<имя-файла-без-расширения>`,
- попадёт в блок «Связанные привычки» на других статьях той же категории.

Никакой регистрации в коде не требуется — `lib/habits.ts` читает папку при
сборке. После добавления просто закоммитьте и запушьте — Vercel
переразвернёт сайт.

## Как добавить материалы в «Привычку дня»

Откройте `content/daily.json` и добавьте элементы в массив
`tongueTwisters` или `poems`. Структура каждого элемента:

```json
{
  "id": "уникальный-slug",
  "type": "tongue-twister" | "poem",
  "difficulty": "easy" | "medium" | "hard",
  "title": "Название или первая строка",
  "author": "Только для стихов",
  "text": "Полный текст с \\n для переносов строк",
  "explanation": "1–2 предложения контекста"
}
```

Не меняйте `id` существующих элементов — на них завязан прогресс пользователей
в `localStorage`.

## Где хранятся данные пользователя

Всё хранится **только в браузере** через `localStorage` под ключами:

- `habitflow:daily:v1` — серия, выученные произведения для /daily
- `habitflow:tracker:v1` — привычки и отметки для /tracker

Никаких отправок на сервер. Никаких cookies слежения. Никакой аналитики.
